# Node.js CI/CD Pipeline Project

This project demonstrates a complete CI/CD pipeline for a Node.js application using Jenkins and GitHub webhooks.

## Technologies Used

- Node.js
- Express.js
- Mocha
- Jenkins
- GitHub Webhooks
- PM2

## CI/CD Pipeline Flow

Developer → Git Push → GitHub → Webhook → Jenkins Pipeline → Test → Deploy

## Features

- Automated testing with Mocha
- Continuous Integration with Jenkins
- Automatic pipeline trigger using GitHub Webhook
- Application deployment using PM2
